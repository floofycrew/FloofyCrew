# {{SOURCE_LABEL}} — a FloofyCrew mod registry

An **unofficial** registry of mods for KiroCrew, read by the FloofyCrew mod
manager (`floofy`). FloofyCrew is not affiliated with KiroCrew or Kiro; nothing
here is endorsed by them. This registry serves the **{{EDITION}}** edition and is
the source the `floofy` CLI of that edition ships with.

What clients fetch (all files at the root, over HTTPS):

| File | What |
|---|---|
| `index.json` + `index.json.sig` | the signed catalogue of mods and versions (schema `index-1`) — generated by `registry_tools build`, never edited by hand |
| `compat.json` + `compat.json.sig` | the compatibility matrix per KiroCrew edition × channel × version (schema `compat-1`), maintained by the FloofyCrew Forge |
| `app-registry.json` | the KiroCrew-compatible index of the app-kind mods, so this repository also works as a federated **KiroCrew app registry** (`floofy registry defaults` adds it as an operator row) |

The signing key for this registry is **`{{KEY_ID}}`** (Ed25519; the public half is
pinned in the FloofyCrew edition adapter). A client refuses an index that does
not verify unless its user explicitly loosens that source
(`floofy registry add <url> --allow-unsigned`, warned and audited).

## Layout

```
registry.json                     this registry's identity: source label, signing key id, record kind, archive URL template, repository pattern
mods/<id>/mod.json                curated record: repo, tags, links
mods/<id>/<version>/floofy.json   the mod's manifest exactly as released
mods/<id>/<version>/release.json  channel, publishedAt, then EITHER tag + files[]{url, sha256, size} (an archive record)
                                  OR link{repo, path, commit, manifestSha256, ref?} + files[]{path, sha256, size} (a link record, pinned by commit)
compat.json, index.json, app-registry.json   generated / maintained as above
masquerade-allow.txt              ids the curators cleared of the host-name check
```

## Tooling

Everything is `registry-tools` from the FloofyCrew repository
(`{{FLOOFYCREW_REPO}}`), standard-library Python 3.12:

```bash
PYTHONPATH=<floofycrew>/floofy-core:<floofycrew>/registry-tools \
  python -m registry_tools build . --app-registry --sign <private key>     # regenerate + sign index.json, app-registry.json
python -m registry_tools sign compat.json --key <private key>              # after the Forge merged a row
python -m registry_tools validate-submission <archive> --registry . --tag <tag>
```
